# Age of War

This folder contains the original browser-delivered Flash game, distributed locally through the bundled Ruffle runtime. The game is launched through `index.html` and is registered in the Game Hub by `game.json`.

The original game client was served from the public CrazyGames game bundle and preserved locally for offline use. The project retains the game files and runtime support needed to run the original SWF without requiring the original website or browser plugin.
