# Toss The Turtle Offline

This folder contains a local copy of the Toss The Turtle game from:

https://foxcns.com/arcade-new/arcade-toss-the-turtle/

Open `index.html` in Microsoft Edge. The game file and the Ruffle Flash runtime are included, so no internet connection is required after the files have been downloaded.

The original game file is kept unchanged at `games/toss-the-turtle.swf`. Ruffle is included under `ruffle/` under its open-source licenses.

## iPad

Extract the zip in the Files app and open `index.html` with Microsoft Edge. If Edge blocks local file execution on a particular iPadOS version, open the same folder through a local static file server on a computer connected to the iPad; the game itself remains offline.
